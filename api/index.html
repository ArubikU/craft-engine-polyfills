API Reference

JavaDoc-style class reference for CraftEngine Polyfills.

dev.arubik.craftengine.machine.render.formula

ClassDescription
PolyFormulaTyped expression engine — compile once, evaluate per tick.
PolyValueSealed union of all value types (Num, Bool, Item, Str, Array, Obj, Null).
PolyContextImmutable evaluation scope — variables + registered PolyClasses.
PolyClassInterface for namespace objects (Block, World, Inventory, etc).
PolyScriptLoads .pf script files with for/while/if and variable assignments.

dev.arubik.craftengine.machine.render

ClassDescription
RendererSpecSealed interface with 9 renderer type records (BetterModel, Particle, etc).
RendererManagerRuntime driver — ticks all renderers per-player via NMS packets.

dev.arubik.craftengine.machine

ClassDescription
MachineDefinitionParsed machine JSON — slots, tanks, bars, upgrades, power, renderers.

dev.arubik.craftengine.contraption.core

ClassDescription
ContraptionEntityRender facade — owns swarms, elements, culling, teleport.
ContraptionStateBrain — block map, NBT, transform, seated riders, physics ID.
