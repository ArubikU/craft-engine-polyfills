Upgrade System & MachineAttributes

Mojang-style attribute modifiers — ADD, MULTIPLY_BASE, MULTIPLY_TOTAL — with per-machine upgrade slot grids.

Overview

Upgrades work like Minecraft's attribute system: each installed upgrade item contributes one or more modifiers on named attributes. The machine collects all modifiers from installed upgrade items each tick and computes final attribute values using exactly Mojang's folding math.

Standard Attributes

Attribute KeyBaseDescription
polyfill:overclock_limit0.0Additional overclock headroom (fraction). Adds to the machine's base_overclock.
polyfill:fuel_efficiency0.0Reduces fuel/gas/energy consumption (fraction). 0.1 = 10% less fuel consumed.
polyfill:generation0.0Output bonus (fraction). 0.05 = 5% extra output items produced.
polyfill:extra_slots0.0Unlocks additional upgrade slots. Integer-rounded at application time.
polyfill:pressure0.0Flat pressure bonus added to pump's stamped fluid pressure (lifts fluid higher).

Modifier Math

Three operations are supported, applied in order:

1. x = base + Σ ADD_VALUE
2. x = x × (1 + Σ ADD_MULTIPLIED_BASE)
3. for each ADD_MULTIPLIED_TOTAL m:  x = x × (1 + m)
OperationJSON name aliasesDescription
ADD_VALUE"add", "add_value", "addition"Flat additive. All modifiers of this type are summed before multipliers apply.
ADD_MULTIPLIED_BASE"multiply_base", "add_multiplied_base"Multiplies the base+flat total. Modifiers of this type are summed into one factor: (1 + Σ).
ADD_MULTIPLIED_TOTAL"multiply_total", "multiply"Each modifier is applied independently: x = x × (1 + m). Stacks multiplicatively.

Defining Upgrades in Machine JSON

"slots": {
  "upgrade": {
    "count": 9,
    "base_unlocked": 3,
    "definitions": {
      "cml:upgrade_iron":    [
        { "attribute": "polyfill:generation", "operation": "add", "value": 0.05 }
      ],
      "cml:upgrade_gold":    [
        { "attribute": "polyfill:generation",      "operation": "add", "value": 0.10 },
        { "attribute": "polyfill:fuel_efficiency", "operation": "add", "value": 0.10 }
      ],
      "cml:upgrade_diamond": [
        { "attribute": "polyfill:generation",      "operation": "add",  "value": 0.18 },
        { "attribute": "polyfill:overclock_limit", "operation": "add",  "value": 0.5  },
        { "attribute": "polyfill:fuel_efficiency", "operation": "add",  "value": 0.15 }
      ],
      "cml:upgrade_scrapped": [
        { "attribute": "polyfill:overclock_limit", "operation": "add", "value": 1.0   },
        { "attribute": "polyfill:fuel_efficiency", "operation": "add", "value": -0.40 }
      ]
    }
  }
}

The key in definitions is the CE item ID of the upgrade item. Multiple upgrades of the same type stack — two iron upgrades contribute +0.05 twice.

NoteThe scrapped upgrade example shows how a single upgrade item can trade one attribute for another: +1.0 overclock_limit at the cost of −0.40 fuel_efficiency. The negative flat modifier is perfectly valid.

Upgrade Slot Modes

Two slot conventions exist:

ModeConfigDescription
Reserved (separate page)"count": N, "base_unlocked": KReserves container indices 0..N−1. These never appear on the main page. A second UI page shows only the upgrade grid.
Inline (main page)"slots": [3,4,5]Upgrade items sit in named menu slots on the main page. No separate upgrade page. Simpler for small machines.

Extra Slots Upgrade

The polyfill:extra_slots attribute unlocks additional upgrade slots up to count. Initially only base_unlocked slots are usable; inserting slot-expander upgrade items reveals more.

"cml:iron_cast":    [{ "attribute": "polyfill:extra_slots", "operation": "add", "value": 2 }],
"cml:gold_cast":    [{ "attribute": "polyfill:extra_slots", "operation": "add", "value": 3 }],
"cml:diamond_cast": [{ "attribute": "polyfill:extra_slots", "operation": "add", "value": 4 }]

Overclock System

The overclock slider lets players trade RPM (and therefore SU) for speed. The slider range is 0..base_overclock + Σ overclock_limit. At overclock N:

  • Machine speed = N × recipe_time ticks (i.e. higher overclock = faster).
  • SU demand = recipe_su × (1 + N)^su_exponent.
WarningHigh su_exponent (1.5+) makes overclocking geometrically expensive. A machine set to overclock 3 with su_exponent 1.5 demands roughly 8× its base SU.

MachineAttributes Java API

public final class MachineAttributes // package: dev.arubik.craftengine.machine.attribute
public static Map<Key, Double> compute(List<Mod> modifiers)

Fold a list of modifiers into final attribute values using Mojang's math. Returns a map of every registered attribute key to its final computed value.

public static void register(Key attribute, double base)

Register a new attribute with a given base value. Use to add custom attributes for plugin extensions.

public record Mod(Key attribute, Operation operation, double amount)

One modifier: bump attribute by amount via operation.

Upgrades in PolyFormula

The Upgrades PolyClass exposes upgrade state to renderer expressions and scripts:

Upgrades.count("cml:upgrade_diamond")    // how many diamond upgrades installed
Upgrades.inventory                        // Array of all items in upgrade grid
Upgrades.slots                            // number of unlocked slots
# In a .pf script: emit extra sparks when diamond upgrades installed
has_diamond = Upgrades.count("cml:upgrade_diamond") > 0

# Calculate total upgrade bonus
upgrade_bonus = 0
for item in Upgrades.inventory {
    upgrade_bonus = upgrade_bonus + item_count(item)
}
