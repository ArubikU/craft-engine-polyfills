Getting Started

Everything you need to install CraftEngine Polyfills and understand its architecture.

Requirements

DependencyVersionRequired
Paper / Folia1.21.11+Required
CraftEngine0.7+Required
Java21+Required
BetterModelLatestOptional
ModelEngine R4R4.0.6+Optional

Installation

  1. Drop craft-engine-polyfills-<version>.jar into your plugins/ folder.
  2. Ensure CraftEngine is installed and loaded before this plugin.
  3. Start the server. Config files and default resource packs are extracted on first run.
  4. Reload with /cep reload after editing any JSON definition.
TipAll machine, multiblock, pipe, and fluid definitions are hot-reloadable — no server restart needed after a /cep reload.

Architecture Overview

CraftEngine Polyfills is organized into these major subsystems:

SubsystemPackageDescription
Machinesmachine/Data-driven block entity machines with recipes, tanks, upgrades, and renderers. No per-machine Java class required.
PolyFormulamachine/render/formula/Typed expression engine used by renderer specs, variable declarations, and .pf scripts.
Renderersmachine/render/Visual layer: BetterModel, ModelEngine, displays, particles, sounds — all driven by PolyFormula.
Multiblocksmultiblock/Multi-block structures assembled by hammer, with mode-based machine definitions and IO rules.
Contraptionscontraption/Moving structures captured into a sub-level with XPBD physics, bearings, and vehicle seats.
Fluid Networkfluid/graph/Graph-solved pressure network for pipes, tanks, valves, and pumps.
Gas Networkfluid/graph/GasEngineSame solver as fluids but for gaseous fluids (steam, nitrogen…).
Blocksblock/Custom block behaviors: fans, lights, redstone diodes, connectable pipes, storage, crops.
Chainerychainery/Physics-coupled chain block & item — rope-like connections between blocks.

Quick Example: Data Machine

The minimum JSON for a working single-slot machine:

{
  "id": "polyfills:my_crusher",
  "recipe_type": "my_crusher",
  "title": "My Crusher",
  "menu_size": 27,
  "fuel_required": false,
  "slots": {
    "input":  [0],
    "output": [2],
    "info":   4,
    "upgrade": { "count": 3, "base_unlocked": 1 }
  },
  "power": { "consumes_stress": true },
  "bars": [
    { "id": "polyfills:progress", "slots": [1], "source": "progress" }
  ]
}

Place the file in plugins/CraftEnginePolyfills/machines/my_crusher.json and run /cep reload. Then in your CraftEngine pack YAML, add a block behavior of type data_machine with machine: polyfills:my_crusher.

NoteThe recipe_type field is the namespace under which this machine's recipes are looked up. It can differ from the machine id, letting you share recipes across machines or replace a Java machine without invalidating recipes.
