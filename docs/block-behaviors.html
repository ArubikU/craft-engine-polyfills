Block Behaviors

CraftEngine Polyfills registers 28 custom block behaviors under the polyfills: namespace. Assign them via the behavior.type key in any CE block YAML.

Machine Behaviors

Behavior IDDescriptionKey Config Fields
polyfills:data_machineFully data-driven single-block machine. Reads recipe_type, slots, tanks, bars from machines/*.json.machine (id), upgrades, bars, buttons
polyfills:machine_pumpFuel-driven fluid pump. Extracts fluid from source blocks below and pushes into copper pipe network.capacity, extract_per_tick, push_per_tick, pressure, extract_tick_rate
polyfills:gas_pumpExtracts gas (e.g. nitrogen) from gas-provider blocks below and pushes into steel pipe network. 6-directional.capacity, mb_per_point, pressure, extract_tick_rate
polyfills:custom_crafterCustom shapeless crafting block with configurable recipe and output slots.recipe_id, input_slots, output_slot
polyfills:rendererAttaches the PolyFormula renderer system to any CE block without requiring a full machine. Supports particles, displays, sounds, BetterModel.variables, renderers (same format as machine JSON)

Pipe & Fluid Behaviors

Behavior IDDescriptionKey Config Fields
polyfills:pipe_blockFluid pipe segment. Auto-connects to adjacent pipe/pump/tank blocks. Uses pipe_types/*.json for fluid type and capacity.pipe_type (Key)
polyfills:gas_pipe_blockGas pipe segment. Connects to gas pump, gas tank, gas valve. Uses steel pipe type for nitrogen/steam.pipe_type (Key)
polyfills:pump_blockSimple always-active fluid pump (no fuel). Lighter-weight alternative to machine_pump.capacity, pressure, extract_tick_rate
polyfills:valve_blockFluid valve — opens/closes fluid flow based on redstone signal.open_on_power (bool)
polyfills:gas_valve_blockGas valve — same as fluid valve but for gas networks.open_on_power
polyfills:fluid_tank_blockMulti-block-style fluid storage. Accepts fluid input from pipes, exposes fill gauge.capacity, fluid_type (optional filter Key)
polyfills:gas_tank_blockGas storage tank. Compatible with nitrogen/steam/heavy_steam gas types.capacity, gas_type (optional filter Key)
polyfills:fluid_block_tankTreats a world fluid block (water source, lava) as a tank connected to the pipe network.fluid_type (Key matching the world fluid)
polyfills:fluid_displayITEM_DISPLAY-based fluid level indicator block. Renders a fluid fill model that scales with tank level.tank_source, fluid_type
polyfills:gas_providerNatural gas source block (e.g. nitrocalcite). Gas pumps extract from blocks with this behavior.gas_type (Key), extraction_points (float, default 1.0)

Physics & Mechanics

Behavior IDDescriptionKey Config Fields
polyfills:fan_blockAir fan — propels entities and particles in a configurable direction. Used for processing (blast cooling, smelting).direction, force, range, requires_rpm
polyfills:spike_blockDeals damage to entities standing on or touching the block.damage, damage_source
polyfills:magnet_blockAttracts or repels item entities within a radius. Direction configurable via redstone.radius, force, attract (bool)
polyfills:spreading_blockBlock that spreads to adjacent blocks over time (like mycelium). Configurable speed and target block.target_block, spread_rate, require_light
polyfills:tearing_block_spawnSpawns entities or particles when a block is broken or placed.spawn_entity, on_break, on_place
polyfills:tearing_crop_blockCrop that grows by tearing — stages defined by block state, harvested when at max age.stages, grow_chance, output
polyfills:vertical_crop_blockCrop that grows upward (like sugarcane) with configurable max height and growth conditions.max_height, grow_chance, requires_fluid_below
polyfills:bubble_blockCreates upward bubble column particle effect and applies slow-falling to entities above.particle_rate, effect_radius

Storage & Logic

Behavior IDDescriptionKey Config Fields
polyfills:storage_blockCustom inventory block (like a barrel/chest variant) with configurable size and CE item support.size, title, allow_hopper
polyfills:shulker_box_hitboxMakes a CE custom block use a shulker-box-like hitbox for entity collision purposes in contraptions.hitbox_size
polyfills:bush_blockPlant/bush block that can be harvested for items. Regrows over time.output, regrow_ticks, require_sunlight
polyfills:change_over_time_blockBlock that transforms into another block after a configurable number of ticks (e.g. drying, curing, oxidizing).next_block, ticks, require_air_above
polyfills:redstone_controllerEmits configurable redstone signal level. Can be toggled by right-click or by adjacent blocks.signal_strength, toggle_on_click
polyfills:redstone_operatorPerforms boolean logic on redstone inputs (AND/OR/NOT/XOR). Up to 4 input faces configurable.operation, input_faces, output_face
polyfills:chainery_blockChain block entity — part of the Chainery conveyor system. Handles item routing and speed.See Chainery docs

Usage Example

Block YAML in plugins/CraftEngine/resources/modern/configuration/block/polyfills/myblock.yml:

blocks:
  cml:my_gas_provider:
    settings:
      template:
        - default:hardness/stone
        - default:sound/stone
    states:
      state: "minecraft:calcite"
      model:
        path: cml:block/nitrocalcite
    behavior:
      type: polyfills:gas_provider
      gas_type: polyfills:nitrogen
      extraction_points: 1.5
blocks:
  cml:my_renderer_block:
    states:
      state: "minecraft:cactus[age=0]"
      model:
        path: cml:block/copper_pipe/null
      entity-renderer:
        item: cml:my_block_item
        rotation: 0
    behavior:
      type: polyfills:renderer
      variables:
        powered: "redstone > 0"
        pulse: "sin(tick() % 40 / 40.0 * TAU) * 0.2"
      renderers:
        - type: particle
          particle: FLAME
          count: "powered ? 3 : 0"
          location: {"x": 0.5, "y": 1.2, "z": 0.5}
          when: powered
        - type: text_display
          text: "'Signal: ' + redstone"
          location: {"x": 0, "y": 2.0, "z": 0}
          billboard: center
          when: "player_in_range(5)"
