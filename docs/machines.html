Machine JSON Config Reference

Every field in a machine definition file, with types, defaults, and examples.

File Location

Place machine definition files in plugins/CraftEnginePolyfills/machines/*.json. They are reloaded with /cep reload.

Top-Level Fields

KeyTypeDefaultDescription
idStrRequiredNamespaced machine identifier, e.g. "polyfills:crusher". Must be unique across all loaded definitions.
recipe_typeStrRequiredRecipe namespace under which recipes are looked up. May differ from id to share recipes with a Java machine.
titleStrRequiredMenu window title (supports lang keys).
menu_sizeIntRequiredChest inventory size: 9, 18, 27, 36, 45, or 54.
fuel_requiredBoolfalseWhether the machine halts without fuel items in its fuel slots.
slotsObjectRequiredSlot configuration. See Slots section.
fluid_tanksArray[]Fluid tank declarations. See Tanks section.
gas_tanksArray[]Gas tank declarations. Same format as fluid_tanks.
ioObjectnullDirectional IO configuration. See IO Configuration.
powerObjectnoneRotational power spec. See Power Spec.
barsArray[]Gauge bars to show. See Bars.
buttonsArray[]Action buttons on the main page. See Buttons.
variablesObject{}Named PolyFormula variable declarations evaluated each tick.
renderersArray[]Visual renderer specs. See Renderer System.
pagingObjectnullMulti-page storage config. See Paging.

Slots

"slots": {
  "input":  [12],
  "output": [14],
  "fuel":   [11, 15],
  "info":   4,
  "upgrade": {
    "count": 9,
    "base_unlocked": 3,
    "definitions": { ... }
  }
}
KeyTypeDescription
inputArray<Int>Menu slot indices that accept input items.
outputArray<Int>Menu slot indices where output items are placed.
fuelArray<Int>Menu slot indices for fuel items. Required when fuel_required: true.
infoInt or ObjectSlot index for the recipe readout icon. Or object with slot, type ("recipe" | "tank"), and source (e.g. "fluid:water_input").
upgradeObjectUpgrade grid configuration. See Upgrade Spec.

Upgrade Spec

KeyTypeDefaultDescription
countInt0Total upgrade slots. Uses reserved container indices 0..count−1 (separate page). Mutually exclusive with slots.
base_unlockedInt1How many slots are usable before any EXTRA_SLOTS upgrade.
slotsArray<Int>nullExplicit menu slot indices for upgrade grid (inline mode). Mutually exclusive with count.
definitionsObject{}Maps CE item key → list of attribute modifier objects. See Upgrade System.

Tanks

"fluid_tanks": [
  { "name": "water_input",  "capacity": 10000, "filter": "polyfills:water" }
],
"gas_tanks": [
  { "name": "steam_output", "capacity": 10000, "filter": "polyfills:steam" }
]
KeyTypeDefaultDescription
nameStrRequiredUnique tank name within this machine. Referenced in bars, info, and PolyFormula.
capacityIntRequiredMaximum fluid capacity in mB.
filterKeynullNamespaced fluid/gas type key that restricts what this tank accepts. Null = accepts any.

Power Spec

"power": {
  "consumes_stress": true,
  "su_exponent": 1.25,
  "stress_grace_ticks": 20,
  "generates_rpm": 0,
  "generates_su": 0,
  "base_overclock": 2.0
}
KeyTypeDefaultDescription
consumes_stressBoolfalseWhether the machine needs rotational supply. False = fuel-only machine.
su_exponentFloat1.25SU scales as (1 + overclock)^su_exponent. >1.0 = overclocking costs more stress.
stress_grace_ticksInt20Ticks the machine keeps running after supply dips below demand.
generates_rpmFloat0RPM this machine adds to the network (generator machines).
generates_suInt0SU capacity this machine contributes.
base_overclockFloat2.0Maximum overclock multiplier before any upgrade modifications.

Bars

"bars": [
  { "id": "polyfills:progress", "slots": [13],     "source": "progress" },
  { "id": "polyfills:fuel",     "slots": [40],     "source": "rpm" },
  { "id": "polyfills:fluid",    "slots": [27, 18], "source": "fluid:water_input" },
  { "id": "polyfills:gas",      "slots": [35, 26], "source": "gas:steam_output" }
]
KeyTypeDefaultDescription
idKeyRequiredBar definition ID from bars/*.json.
slotsArray<Int>RequiredMenu slot indices the bar occupies. Multiple slots = multi-cell bar.
sourceStrbar idWhat the gauge reads: "progress", "fuel", "rpm", "fluid:<name>", or "gas:<name>".

Buttons

"buttons": [
  {
    "slot": 33,
    "icon": "cml:upgrade_button",
    "action": "open_page:1",
    "name": "polyfill.ui.upgrades",
    "lore": ["polyfill.ui.upgrades_desc"]
  },
  {
    "slot": 29,
    "icon": "cml:overclock_button",
    "action": "open_page:2",
    "name": "polyfill.ui.overclock",
    "locked_icon": "cml:locked_icon",
    "locked_when": "no_overclock"
  }
]
KeyTypeDefaultDescription
slotIntRequiredMenu slot for this button.
iconStrRequiredCE item ID for the button icon.
actionStrRequiredButton action: "open_page:N" (open page N), "deplete_fluid", "deplete_gas".
nameStr""Display name — a lang key or literal string.
loreArray<Str>[]Tooltip lines — lang keys or literals.
locked_iconStrnullAlternate icon shown when the button is locked.
locked_whenStrnullCondition that locks this button. Currently supports "no_overclock" (machine has no overclock headroom).

Paging (Multi-page Storage)

"paging": {
  "pages": 3,
  "slots": 45,
  "prev_slot": 45,
  "next_slot": 53,
  "indicator_slot": 49
}
KeyTypeDefaultDescription
pagesInt1Number of pages. 1 = ordinary non-paged storage.
slotsInt0Storage slots per page.
prev_slotInt-1Menu slot for the previous-page button. -1 = none.
next_slotInt-1Menu slot for the next-page button. -1 = none.
indicator_slotInt-1Menu slot showing "page N/M". -1 = none.

IO Configuration

IO configuration controls which faces accept or emit which resource types. Defined directly in machine JSON or in multiblock mode JSON.

"io": {
  "default": "closed",
  "rules": [
    { "y_above": 0, "input":  { "types": ["item"], "faces": ["all_but_down"] } },
    { "y": 0,       "input":  { "types": ["item"], "faces": ["horizontal"] } },
    { "y_below": 0, "output": { "types": ["item"], "faces": ["down"] } }
  ]
}
KeyTypeDescription
defaultStr"open" — all faces open. "closed" — all faces closed.
rulesArrayList of directional IO rules (applies to multiblock members).

Complete Example: Crusher

{
  "id": "polyfills:crusher",
  "recipe_type": "crusher",
  "title": "Crusher",
  "menu_size": 54,
  "fuel_required": false,
  "slots": {
    "input":  [12],
    "output": [14],
    "info":   4,
    "upgrade": {
      "count": 9,
      "base_unlocked": 3,
      "definitions": {
        "cml:upgrade_iron":    [{ "attribute": "polyfill:generation",  "operation": "add", "value": 0.05 }],
        "cml:upgrade_diamond": [
          { "attribute": "polyfill:generation",      "operation": "add", "value": 0.18 },
          { "attribute": "polyfill:overclock_limit", "operation": "add", "value": 0.5  },
          { "attribute": "polyfill:fuel_efficiency", "operation": "add", "value": 0.15 }
        ]
      }
    }
  },
  "power": {
    "consumes_stress": true,
    "su_exponent": 1.25,
    "stress_grace_ticks": 20
  },
  "bars": [
    { "id": "polyfills:progress", "slots": [13], "source": "progress" },
    { "id": "polyfills:fuel",     "slots": [40], "source": "rpm" }
  ],
  "buttons": [
    {
      "slot": 33, "icon": "cml:upgrade_button", "action": "open_page:1",
      "name": "polyfill.ui.upgrades"
    },
    {
      "slot": 29, "icon": "cml:overclock_button", "action": "open_page:2",
      "name": "polyfill.ui.overclock",
      "locked_icon": "cml:locked_icon", "locked_when": "no_overclock"
    }
  ],
  "variables": {
    "running":    "processing && rpm > 0",
    "speed_mult": "max(0.05, overclock)"
  },
  "renderers": [
    {
      "type": "bettermodel",
      "model_id": "crusher",
      "animation": "on",
      "speed": "speed_mult",
      "when": "running",
      "run": "crusher"
    }
  ]
}

Recipe Format

Recipes live in plugins/CraftEnginePolyfills/recipes/*.json. The type field must match the machine's recipe_type.

{
  "type": "crusher",
  "inputs": [
    { "item": "minecraft:cobblestone", "amount": 1 }
  ],
  "outputs": [
    { "item": "minecraft:gravel", "amount": 1, "chance": 1.0 },
    { "item": "minecraft:flint",  "amount": 1, "chance": 0.1 }
  ],
  "time": 100,
  "rpm": 20,
  "su": 16
}
KeyTypeDescription
typeStrMust match the machine's recipe_type.
inputsArrayList of input requirements. Each: item (material/CE key), amount. Can also be tag.
outputsArrayList of outputs. Each: item, amount, chance (0.0–1.0).
fluid_inputsArrayFluid requirements: fluid (fluid type key), amount (mB).
fluid_outputsArrayFluid outputs.
gas_inputs / gas_outputsArrayGas requirements/outputs.
xp_outputFloatXP to award on completion.
timeIntProcessing ticks.
rpmIntMinimum RPM required (0 = no requirement).
suIntStress units this recipe demands from the network.
conditionsArrayOptional conditions. Currently supports block_below.

Fuels live in plugins/CraftEnginePolyfills/fuels/*.json.
