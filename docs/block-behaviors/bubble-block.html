polyfills:bubble_block

Creates a column of vanilla bubble_column blocks above or below the custom block in water-filled cells, simulating a magma-block or soul-sand style vent.

Java class: dev.arubik.craftengine.block.behavior.BubbleBlockBehavior
Registered as: BlockBehaviors.POLYFILL_BUBBLE_BLOCK
Block entity: none

Description

On placement the behavior schedules a recurring block tick every 6 ticks. On each tick it scans up to limit water cells in the configured direction and replaces each water cell with a vanilla bubble_column block — using drag=true (pulls down, like magma) or drag=false (pushes up, like soul sand), controlled by the drag setting.

When the source block is removed, all bubble-column blocks in the column are converted back to water.

Configuration

KeyTypeDefaultDescription
directionStringupScan direction for placing bubble columns. up = scan upward from the source block; down = scan downward.
dragStringupBubble column drag mode. up → drag=false (push-up soul-sand style); any other value → drag=true (pull-down magma style).
limitint100Maximum number of water cells to convert into bubble columns.

Example

blocks:
  cml:vent_stone:
    settings:
      template:
        - default:hardness/stone
    states:
      state: "minecraft:deepslate"
      model:
        path: cml:block/vent_stone
    behavior:
      type: polyfills:bubble_block
      direction: up
      drag: down     # drag=true (magma-style pull)
      limit: 20

Implementation Notes

The behavior uses scheduleBlockTick with a delay of 6 ticks rather than the standard random-tick system, so it fires consistently regardless of the server's random-tick speed setting. The scan walks through water-source blocks only — flowing water and non-water blocks are skipped.
