polyfills:data_multiblock_machine

A machine that is also a multiblock - described entirely by data. The machine lives inside the multiblock's assembled mode, not beside it.

Java class: dev.arubik.craftengine.machine.block.behavior.DataMultiBlockBehavior
Factory key: polyfills:data_multiblock_machine
Block entity: DataMultiBlockMachineBlockEntity
Related docs: Machine JSON Reference · data_machine

Description

polyfills:data_machine covers machines that are a single block. A machine that must be physically assembled - for example a refinery with a mixer tower on top - needs the multiblock half as well: a shape to match, a part block to convert when assembled, and per-cell I/O configuration.

Rather than widening the single-block behavior and risking breakage for existing machines, this is a separate behavior that reads the same MachineDefinition plus a MultiBlockDefinition. The design is deliberate: a bare shape on its own does nothing, and one core block can assemble into different machines depending on the shell built around it.

Mode-based machine selection When a core block has more than one mode configured, the behavior tries each mode's shape in order and keeps the first that matches. The winning mode determines which MachineDefinition the block entity is initialised with.

Example

blocks:
  cml:refinery_core:
    settings:
      template:
        - default:hardness/iron
    states:
      state: "minecraft:copper_block"
      model:
        path: cml:block/refinery_core
    behavior:
      type: polyfills:data_multiblock_machine
      multiblock: polyfills:refinery     # multiblocks/refinery.json
      menu_size: 54
      bars:
        energy:
          slot: 10
          type: polyfills:energy_bar

Implementation Notes

DataMultiBlockBehavior extends MultiBlockBehavior. When the player assembles the required shell around the core block, tryFormMachine() iterates the configured modes and calls the parent class shape-match logic. On a successful match it records the winning mode and the parent spawns a DataMultiBlockMachineBlockEntity initialised with that mode's machine definition.

Disassembling the multiblock tears down the block entity and the part blocks revert to their standalone state.
