polyfills:data_machine

The single block behavior behind every data-defined machine. Point a block at a machines/*.json definition and get a fully working machine — no Java required.

Java class: dev.arubik.craftengine.machine.block.behavior.DataMachineBehavior
Factory key: polyfills:data_machine
Block entity: DataMachineBlockEntity
Related docs: Machine JSON Reference · Upgrade System · Gauge Bars

Description

The split between block config and machine JSON is deliberate: the machines/*.json file says what the machine is — its recipe namespace, slot roles, tank layout, and I/O faces — while the block YAML says what it looks like through the GUI layout, renderer specs, and upgrade slot definitions. Neither side had to grow a second way to express the same thing.

Upgrade definitions may live in either the block YAML (upgrades: section) or in the machine JSON (upgrades.definitions block). The machine JSON version takes precedence when both are present.

Configuration

KeyTypeDefaultDescription
machineKeyrequiredNamespaced ID pointing to a machine definition file (machines/<id>.json). Example: polyfills:grinder.
menu_sizeint54GUI inventory size (multiples of 9; 9–54).
barsMap{}Gauge bar definitions. See Gauge Bars.
upgradesMap{}Map of CE item ID → list of attribute modifier objects. Fallback when the machine JSON does not define upgrades. See Upgrade System.
buttonsList[]GUI button definitions (slot, icon, action).
connectable_facesList<String>all facesFaces that connect to pipe/cable networks (e.g. [UP, DOWN]).
renderersList[]PolyFormula renderer specs; same format as polyfills:renderer.
variablesMap{}PolyFormula variable declarations for renderer expressions.

Example

blocks:
  cml:grinder:
    settings:
      template:
        - default:hardness/iron
        - default:sound/metal
    states:
      state: "minecraft:iron_block"
      model:
        path: cml:block/grinder
    behavior:
      type: polyfills:data_machine
      machine: polyfills:grinder       # reads machines/grinder.json
      menu_size: 54
      bars:
        energy:
          slot: 10
          type: polyfills:energy_bar
        progress:
          slot: 13
          type: polyfills:progress_bar
      upgrades:
        cml:speed_upgrade:
          - { attribute: processing_speed, operation: multiply_base, value: 0.25 }
        cml:efficiency_upgrade:
          - { attribute: energy_consumption, operation: multiply_base, value: -0.15 }

Implementation Notes

DataMachineBehavior extends MachineBlockBehavior and delegates block-entity creation to DataMachineBlockEntity. On creation the entity receives the machine definition, menu config, bar list, and upgrade map. The machine JSON is resolved lazily at first load so hot-reloading the JSON updates running machines without a server restart.

For machines that require a multi-block structure (e.g. a refinery assembled from multiple parts), use polyfills:data_multiblock_machine instead.
