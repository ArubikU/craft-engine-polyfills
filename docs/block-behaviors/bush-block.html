polyfills:bush_block

A multi-cell tall plant (like pointed dripstone or bamboo). Stacks vertically on itself, tracks growth stages via an age block property, and can only survive on configurable ground types.

Java class: dev.arubik.craftengine.block.behavior.BushBlockBehavior
Registered as: BlockBehaviors.POLYFILL_BUSH_BLOCK
Block entity: none
Block property required: age (IntegerProperty)

Description

On placement the tip segment's age property is set to its maximum or minimum value (controlled by age-direction). Age values decrease down the column so each segment below the tip carries a progressively lower age, letting packs use different models per stage.

The behavior implements canSurvive: if the block below is not in the allowed list (or is in the blacklist when blacklist: true), the block pops off. If the block below is the same custom block and stackable: true, the column grows.

Configuration

KeyTypeDefaultDescription
bottom-block-tagsList<Key>[]MC block tags the block may survive on (e.g. minecraft:dirt). Prefixed with # in tag syntax.
bottom-blocksList<String>[]Explicit vanilla or CE block IDs (optionally with block-state suffix) the block may survive on.
blacklistboolfalseWhen true, the tag/block lists act as a blacklist instead of an allowlist - the block survives on everything except the listed entries.
stackableboolfalseWhether the block can be placed on top of another block of the same type (forming a tall column).
age-directionStringupup sets the tip to maximum age and decrements downward; down sets the tip to minimum age and increments downward.
delayint (ticks)0Scheduled tick delay used by the parent AbstractCanSurviveBlockBehavior.

Example

blocks:
  cml:crystal_spike:
    settings:
      template:
        - default:hardness/stone
    properties:
      age:
        type: integer
        values: [0, 1, 2, 3]
    states:
      state: "minecraft:amethyst_block"
      models:
        - { when: "age=3", path: cml:block/crystal_spike_tip }
        - { when: "age=2", path: cml:block/crystal_spike_mid_upper }
        - { when: "age=1", path: cml:block/crystal_spike_mid_lower }
        - { when: "age=0", path: cml:block/crystal_spike_base }
    behavior:
      type: polyfills:bush_block
      stackable: true
      age-direction: up
      bottom-block-tags:
        - minecraft:base_stone_overworld

Implementation Notes

When the bottom-most segment of a column is removed (affectNeighborsAfterRemoval), the behavior walks upward and converts all consecutive same-type blocks back to water (if waterlogged) or removes them. The waterlogged state is preserved: if any segment in the column is waterlogged the replacement state inherits that flag.
