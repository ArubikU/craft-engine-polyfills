polyfills:fan_block

Gas-powered encased fan (Create-style). Consumes gas to propel entities in its output direction and to process items placed in its airstream via smelting, blasting, washing, or custom fan recipes.

Java class: dev.arubik.craftengine.block.behavior.FanMachineBehavior
Registered as: BlockBehaviors.POLYFILL_FAN_BLOCK
Block entity: FanMachineBlockEntity
Related docs: Machine JSON Reference · Gauge Bars

Description

The fan draws gas from an adjacent gas pipe or tank each tick (gas_per_tick mB). While gas is available it emits an airflow beam in the block's facing direction. Items dropped or hoppered into the airstream region are processed according to their matching fan recipe — smelting, blasting, washing, or any custom FanProcess. Each recipe type can emit a different particle in the downstream region.

Entity propulsion applies a velocity impulse to all entities in the beam each tick. The push strength and range per gas type are configured via the gases map.

Configuration

gas_bufferint (mB)4000Internal gas storage capacity.
gas_per_tickint (mB)50Gas consumed per server tick while the fan is running.
processing_intervalint (ticks)40Ticks between item-processing attempts in the airstream.
tickDelayint (ticks)2Minimum ticks between entity push pulses.
gasesMapsee belowPer-gas-type configuration block. Keys are gas type names (e.g. steam, heavy_steam); each entry is a map with push_strength (double), push_limit (int, max entities per pulse), and particle (Bukkit Particle name).
process_particlesMap{}Map of FanProcess enum name → Bukkit Particle name. Displayed downstream of the processing block (e.g. smelting: FLAME).
passableBlocksList<Key>[]Additional CE custom blocks the airflow passes through (air, fire, water, and lava are always passable).
upgradesMap{}Upgrade item → attribute modifier list.
barsMap{}GUI gauge bars.
menu_sizeint54GUI size.

Example

blocks:
  cml:steam_fan:
    states:
      state: "minecraft:iron_block"
      model:
        path: cml:block/steam_fan
    behavior:
      type: polyfills:fan_block
      gas_buffer: 6000
      gas_per_tick: 80
      processing_interval: 30
      gases:
        steam:
          push_strength: 0.12
          push_limit: 6
          particle: CLOUD
        heavy_steam:
          push_strength: 0.20
          push_limit: 4
          particle: SMOKE_NORMAL
      process_particles:
        smelting: FLAME
        washing: SPLASH
      bars:
        gas_level:
          slot: 13
          type: polyfills:gas_bar

Fan process types

The FanProcess enum values map to recipe categories:

  • SMELTING — applies furnace smelting recipes
  • BLASTING — applies blast furnace recipes
  • SMOKING — applies smoker recipes
  • WASHING — applies CEP fan-wash recipes
  • Custom values registered via CEP recipe extensions
