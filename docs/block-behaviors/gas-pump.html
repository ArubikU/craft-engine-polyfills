polyfills:gas_pump

Full-machine gas pump. Extracts gas (e.g. nitrogen) from polyfills:gas_provider source blocks below and pushes it into a connected steel-pipe gas network. Supports upgrades, a configurable GUI, and gauge bars.

Java class: dev.arubik.craftengine.machine.block.behavior.GasPumpBehavior
Factory key: polyfills:gas_pump
Block entity: GasPumpBlockEntity
Related docs: Pipes & Fluids · Upgrade System · Gauge Bars

Description

The pump scans downward for blocks carrying polyfills:gas_provider behavior each extraction tick, draws mb_per_point × extraction_points mB from the provider into an internal gas buffer, and then pushes the buffer contents out through its UP face into the gas pipe network above. The pressure value determines how far the gas is driven against a network back-pressure. All extraction and push rates are affected by installed upgrades.

Gas network vs fluid network Gas pumps connect to polyfills:gas_pipe_block segments, not to fluid pipes. The two networks are physically separate.

Configuration

capacityint (mB)4000Internal gas buffer capacity in milli-buckets.
mb_per_pointint50mB extracted from the provider per extraction point per tick cycle.
pressureint100Pump pressure; higher values push against greater network resistance.
extract_tick_rateint20Server ticks between extraction cycles.
upgradesMap{}Upgrade item ID → list of attribute modifier objects. Attributes: capacity, pressure, extract_tick_rate, mb_per_point.
barsMap{}GUI gauge bar definitions.
menu_sizeint54GUI inventory size.
buttonsList[]GUI button definitions.
connectable_facesList<String>all facesFaces that connect to the gas pipe network.

Example

blocks:
  cml:gas_pump:
    settings:
      template:
        - default:hardness/iron
    states:
      state: "minecraft:iron_block"
      model:
        path: cml:block/gas_pump
    behavior:
      type: polyfills:gas_pump
      capacity: 8000
      mb_per_point: 75
      pressure: 150
      extract_tick_rate: 10
      upgrades:
        cml:pressure_upgrade:
          - { attribute: pressure, operation: add, value: 50 }
      bars:
        gas_level:
          slot: 13
          type: polyfills:gas_bar

Dependencies

  • Requires at least one polyfills:gas_provider block positioned below the pump (the pump scans downward).
  • Requires at least one connected polyfills:gas_pipe_block segment on the pump's UP face to move extracted gas.
