polyfills:change_over_time_block

Transforms a custom block into a different block on random tick, with a configurable probability. Models drying, curing, oxidation, or any time-based block transition.

Java class: dev.arubik.craftengine.block.behavior.ChangeOverTimeBlockBehavior
Registered as: BlockBehaviors.POLYFILL_CHANGE_OVER_TIME_BLOCK
Block entity: none

Description

Each random tick, the behavior generates a random float between 0 and 1. If the value is less than delay the block is replaced by next-block, preserving the current block's property values (e.g. age, facing) where the target block also has those properties. A BlockFormEvent is fired before the replacement, allowing other plugins to cancel the transition.

Probability tuning The default delay of ≈ 0.0569 matches vanilla grass-spreading speed. At 3 random-ticks/second in a loaded chunk, delay: 0.05 gives a median transition time of roughly 14 seconds. Set delay: 1.0 for an instant transition on first tick.

Configuration

KeyTypeDefaultDescription
next-blockKeyrequiredNamespaced ID of the CE custom block to transform into. The block must be registered. Block property values are carried over where property names match.
delayfloat (0–1)0.05689Probability of transformation per random tick. Higher values = faster transformation.

Example — oxidizing copper plate

blocks:
  cml:fresh_copper_plate:
    states:
      state: "minecraft:copper_block"
    behavior:
      type: polyfills:change_over_time_block
      next-block: cml:oxidized_copper_plate
      delay: 0.02     # slow oxidation

  cml:oxidized_copper_plate:
    states:
      state: "minecraft:oxidized_copper"
    # no behavior needed — final form

Example — multi-stage drying

Chain the behavior across several blocks to produce a multi-stage transition (wet clay → damp clay → dry clay):

behavior:
  type: polyfills:change_over_time_block
  next-block: cml:damp_clay
  delay: 0.04
