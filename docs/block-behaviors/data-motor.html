polyfills:data_motor

Data-driven rotational motor block. Generates RPM and stress units (SU) from fuel or gas consumption. Configuration via motors/*.json.

Java class: dev.arubik.craftengine.rotation.DataMotorBehavior
Block entity: dev.arubik.craftengine.rotation.DataMotorBlockEntity
Registered as: BlockBehaviors.POLYFILL_DATA_MOTOR
Motor definition: src/main/resources/motors/gas_motor_mk1.json

Description

A motor consumes gas (steam, heavy_steam, nitrogen) from a connected steel pipe network and generates rotational power (RPM + SU). The generated values depend on the gas type consumed — heavier gas = more power.

Motors support:

  • Multiple gas type inputs with different RPM/SU outputs per type
  • Overclock system (same as machines)
  • Upgrade slots (same attribute system as data_machine)
  • Data-driven renderers (BetterModel animation driven by RPM)
  • On/Off block states (activated property)

Block YAML Configuration

behavior:
  type: polyfills:data_motor
  motor: polyfills:gas_motor_mk1   # references motors/*.json
  upgrades:
    cml:upgrade_iron:
      - { attribute: polyfill:fuel_efficiency, operation: add, value: 0.1 }
  bars:
    fuel:
      slots: [40]
      # ... same bar format as data_machine

Motor JSON (motors/gas_motor_mk1.json)

{
  "id": "polyfills:gas_motor_mk1",
  "gas_inputs": {
    "steam":       { "rpm": 32,  "su": 64,   "mb_per_tick": 10 },
    "heavy_steam": { "rpm": 64,  "su": 1024, "mb_per_tick": 20 }
  },
  "menu_size": 54,
  "fuel_slots": [31],
  "info_slot": 4,
  "renderers": [],
  "variables": {}
}
