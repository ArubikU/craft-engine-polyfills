polyfills:pipe_block

Fluid pipe segment. Auto-connects to adjacent pipes, pumps, valves, and tanks to form a fluid transport network. Capacity and throughput are determined by the pipe's PipeType.

Java class: dev.arubik.craftengine.fluid.behavior.PipeBehavior
Registered as: BlockBehaviors.POLYFILL_PIPE_BLOCK
Block entity: PersistentBlockEntity (stores buffered fluid)
Related docs: Pipes & Fluids Network Reference

Description

When placed, the pipe automatically connects (via ConnectedBlockBehavior) to all adjacent blocks that implement FluidCarrier — other pipes, pumps, valves, and tanks. Fluid is moved through the network each tick up to the pipe type's transferPerTick limit, with round-robin output direction selection to distribute flow evenly.

Right-clicking a pipe with a wrench or similar CE tool shows its current fluid contents and connection state. Right-clicking with an empty bucket draws fluid out; right-clicking with a filled bucket pours fluid in, subject to the pipe's accepted fluid type.

Pipe types Capacity, transfer rate, and accepted fluid type are defined in pipe_types/*.json data files, not in the block YAML. The COPPER tier is the built-in default. Registering new tiers requires a data file only — no Java.

Configuration

KeyTypeDefaultDescription
pipe_typeKeypolyfills:copperNamespaced ID of the PipeType definition. Controls buffer capacity, mB/tick throughput, and fluid type filter.

Example

blocks:
  cml:copper_pipe:
    settings:
      template:
        - default:hardness/copper
        - default:sound/metal
    states:
      state: "minecraft:copper_block"
      model:
        path: cml:block/copper_pipe
    behavior:
      type: polyfills:pipe_block
      pipe_type: polyfills:copper    # pipe_types/copper.json

  cml:steel_pipe:
    states:
      state: "minecraft:iron_block"
      model:
        path: cml:block/steel_pipe
    behavior:
      type: polyfills:pipe_block
      pipe_type: polyfills:steel

Related behaviors

  • polyfills:pump_block — simple always-active fluid pump (no fuel) that feeds into pipe networks.
  • polyfills:valve_block — opens/closes flow based on redstone signal.
  • polyfills:fluid_tank_block — storage tank that connects to pipe networks.
  • polyfills:gas_pipe_block — equivalent for gas networks.
