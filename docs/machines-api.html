Inner Records

public record PowerSpec( boolean consumesStress, double suExponent, int stressGraceTicks, float generatesRpm, int generatesSu, float baseOverclock )

Rotational power configuration. Use PowerSpec.none() for machines with no rotational involvement.

  • consumesStress — whether the machine needs a rotational supply at all.
  • suExponent — SU scales as (1+overclock)^suExponent. 1.25 = typical, >1 means overclocking costs disproportionately more.
  • stressGraceTicks — ticks the machine keeps running after supply dips (prevents flicker on momentary wobble).
  • generatesRpm / generatesSu — for generator machines.
  • baseOverclock — max overclock before upgrades.
public record TankSpec(String name, int capacity, Key filter)

A fluid or gas tank. filter is null for an unfiltered tank.

public record UpgradeSpec(int count, int baseUnlocked, int[] explicitSlots)

Upgrade grid. isInline() returns true when explicitSlots is non-null (inline mode). slots() returns the actual container indices. size() returns the total slot count regardless of mode.

public record BarRef(Key bar, int[] slots, String source)

A gauge bar reference. source selects what the bar reads: "progress", "fuel", "rpm", or "fluid:<name>" / "gas:<name>".

public record InfoSpec(int slot, String type, String source)

Readout icon configuration. type is "recipe" or "tank". isTank() helper returns true for tank type.

public record PagingSpec(int pages, int slots, int prevSlot, int nextSlot, int indicator)

isPaged() returns true when pages > 1.

public record ButtonSpec(int slot, String icon, String action, String name, List<String> lore, String lockedIcon, String lockedWhen)

A UI action button. action values: "open_page:N", "deplete_fluid", "deplete_gas".

RendererManager

public class RendererManager // package: dev.arubik.craftengine.machine.render

Manages all display entities for one machine block entity. Evaluates renderer specs each tick.

public RendererManager( List<RendererSpec> specs, Map<String, VariableSpec> variables )

Creates a manager from a list of renderer specs and variable declarations.

public void tick(MachineRenderContext context)

Evaluate all specs against the context and update spawned display entities. Called each tick by the block entity.

public void destroy()

Remove all spawned display entities from the world (called on block break or chunk unload).
