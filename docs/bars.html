Bars & Gauges

Progress indicators, fuel meters, fluid level and gas gauges — defined in bars/*.json and referenced by machine JSON.

Overview

A bar is a multi-level visual gauge that occupies one or more menu slots. The server selects which item to display in each slot based on the current fill level, cycling through a set of pre-rendered icons.

Bars are defined in plugins/CraftEnginePolyfills/bars/*.json and referenced by their ID in machine definitions under the "bars" array.

Bar File Format

{
  "id": "polyfills:progress",
  "model": "row",
  "name": "lang:polyfill.ui.progress",
  "generate": {
    "empty_icon": "cml:gui_empty",
    "lore": ["%percent%%"],
    "parts": [ { "levels": 16 } ],
    "types": { "default": "cml:progress_%level%" }
  }
}
KeyTypeDefaultDescription
idKeyRequiredNamespaced bar ID referenced in machine definitions.
modelStr"row"Layout model. "row" = single horizontal row of items. "column" = vertical column.
nameStr""Display name for the bar (lang key or literal).
generateObjectRequiredIcon generation spec. See below.

Generate Spec

KeyTypeDescription
empty_iconStrCE item ID for empty/zero-level slots.
loreArray<Str>Tooltip lines. %percent% is replaced with fill percent, %level% with current level index.
partsArrayList of bar segment definitions. Each has a levels count (number of icon levels for this segment).
typesObjectIcon patterns. Key "default" applies to all segments unless a segment-specific key is given. Value is a CE item ID pattern where %level% is substituted.

Built-in Bars

These bars are shipped with the plugin and can be referenced directly in machine JSON:

polyfills:progress

{
  "id": "polyfills:progress",
  "model": "row",
  "name": "lang:polyfill.ui.progress",
  "generate": {
    "empty_icon": "cml:gui_empty",
    "lore": ["%percent%%"],
    "parts": [ { "levels": 16 } ],
    "types": { "default": "cml:progress_%level%" }
  }
}

16-level progress bar. Reference as "source": "progress".

polyfills:fuel

{
  "id": "polyfills:fuel",
  "model": "row",
  "name": "lang:polyfill.ui.fuel",
  "generate": {
    "empty_icon": "cml:fuel_empty",
    "lore": ["%percent%%"],
    "parts": [ { "levels": 14 } ],
    "types": { "default": "cml:fuel_%level%" }
  }
}

14-level fuel/RPM bar. Reference as "source": "fuel" or "source": "rpm".

polyfills:fluid

{
  "id": "polyfills:fluid",
  "model": "column",
  "name": "lang:polyfill.ui.fluid",
  "generate": {
    "empty_icon": "cml:fluid_empty",
    "lore": ["%level% mB"],
    "parts": [ { "levels": 8 } ],
    "types": { "default": "cml:fluid_%level%" }
  }
}

8-level fluid column gauge. Reference as "source": "fluid:tank_name". Multiple slots fill from bottom to top.

polyfills:gas

{
  "id": "polyfills:gas",
  "model": "column",
  "name": "lang:polyfill.ui.gas",
  "generate": {
    "empty_icon": "cml:gas_empty",
    "lore": ["%level% mB"],
    "parts": [ { "levels": 8 } ],
    "types": { "default": "cml:gas_%level%" }
  }
}

8-level gas column gauge. Reference as "source": "gas:tank_name".

polyfills:rpm

RPM / stress indicator. Reference as "source": "rpm".

Using Bars in Machine Definitions

"bars": [
  {
    "id": "polyfills:progress",
    "slots": [13],
    "source": "progress"
  },
  {
    "id": "polyfills:fuel",
    "slots": [40],
    "source": "rpm"
  },
  {
    "id": "polyfills:fluid",
    "slots": [27, 18, 9, 0],
    "source": "fluid:water_input"
  },
  {
    "id": "polyfills:gas",
    "slots": [35, 26, 17, 8],
    "source": "gas:steam_output"
  }
]
TipFluid and gas column bars use multiple slots filled bottom-to-top. List slots from bottom to top so the fill animation looks correct. In the example above, slot 27 is the bottom of the 4-tall fluid column.

Source Values

SourceDescription
progressRecipe progress fraction (0–1).
fuelFuel burn fraction (0–1) — how much of the current fuel item remains.
rpmRPM fraction of machine's maximum RPM.
fluid:<tank_name>Fill fraction of the named fluid tank.
gas:<tank_name>Fill fraction of the named gas tank.

Java API

public class BarDefinition // package: dev.arubik.craftengine.machine.menu.bar

Holds the parsed bar spec. Loaded from JSON by BarLoader.

public class MachineBar // package: dev.arubik.craftengine.machine.menu.bar

A live bar instance attached to one machine menu. Updates its slot items each time the machine's state changes.

public void update(double fraction)

Update the bar to the given fill fraction (0.0–1.0), selecting appropriate icon items for each slot.
