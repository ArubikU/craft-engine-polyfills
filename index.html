CraftEngine Polyfills

Data-driven extension layer for CraftEngine — machines, contraptions, fluid rendering, and a powerful PolyFormula scripting engine.

⚠️ Documentation is being written. Pages will be added progressively.
Core

PolyFormula Engine

Typed expression engine for renderer conditions, animations, and positions.

  • PolyValue types: Num, Bool, Item, Str, Array, Obj
  • 30+ built-in functions (sin, clamp, map, filter…)
  • % operator, ternary ?:, null-coalescing ??
  • .pf script files with for/while loops
Rendering

renderers System

Data-driven visual effects for any machine, multiblock, motor, or CE block.

  • BetterModel, ModelEngine, ItemDisplay, TextDisplay
  • Particle (shaped: disc, sphere, cylinder…)
  • Sound, ArmorStand, BlockDisplay
  • location field: relative offset or absolute world pos
  • positions array for multi-point rendering
Context

PolyClasses

Rich cross-integrated value system available in every expression.

  • Machine, MultiBlock, Contraption, World, Location
  • Player, Entity, Inventory, Block, Item
  • FluidTanks, GasTanks, Upgrades, Workbench
  • Full chaining: World.block(x,y,z).redstone
Machines

Data-Driven Machines

Define machines entirely in JSON — no Java required.

  • slots, tanks, bars, buttons, paging
  • upgrade.definitions in machine JSON
  • MachineAttributes: generation, overclock_limit, fuel_efficiency
  • MultiBlock machines with per-part rendering
Contraptions

Contraption System

Moving structures with physics, fluid rendering, and machine elements.

  • Entity culling (distance + frustum, configurable)
  • Vanilla fluid rendering with CE item patterns
  • ContraptionMachineRendererElement
  • Contraption PolyClass: speed, riders, anchor_entity
Scripting

.pf Script Files

PolyScript files in scripts/ folder, referenced by renderers via "run": "name".

  • Named variable assignments
  • if / else if / else blocks
  • for item in array: loops
  • while condition: loops (max 1000 iterations)
  • i++, i--, i += expr operators
Behaviors

polyfill:renderer Behavior

Add the renderer system to any CE custom block without a machine.

  • Full PolyFormula context (redstone, block state, container)
  • Same renderer types as machines
  • Particles, text, item displays, sounds
