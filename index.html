CraftEngine Polyfills

A Paper 1.21.11 plugin that extends CraftEngine with data-driven machines, multiblocks, contraptions, fluid pipe networks, and the PolyFormula scripting engine.

Paper 1.21.11 CraftEngine 0.7+ Java 21 BetterModel support
📖 Get Started ⚙ Machine Config 📝 PolyFormula

What's included

⚙

Data-Driven Machines

Define machines entirely in JSON — slots, tanks, upgrades, recipes, gauges and renderers. No Java required.

 📝

PolyFormula Engine

80+ built-in functions, PolyClasses (Inventory, Machine, World, Player…), .pf scripts with if/for, compiled per-tick.

 🎥

Renderer System

BetterModel, ModelEngine, ItemDisplay, TextDisplay, BlockDisplay, Particle, Sound — all formula-driven.

 🔄

Contraption System

Moving structures with XPBD physics, bearing blocks, piston bearings, vehicle control and entity culling.

 🌳

Fluid & Gas Networks

Graph-solved pipe networks with pressure, conductance, tanks, valves, pumps, and visual fill indicators.

 📈

Upgrade System

Mojang-style attribute modifiers (ADD / MULTIPLY_BASE / MULTIPLY_TOTAL) with per-machine upgrade slot grids.

 📊

Bars & Gauges

Progress bars, fuel meters, fluid and gas level indicators — defined in bars/*.json, referenced by machine JSON.

 📄

Java API

DataMachineBlockEntity, MachineDefinition, RendererManager — full class and method documentation.
